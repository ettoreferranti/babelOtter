# Re-pitch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select a text, confirm the audience it should now address (last one pre-selected, Return starts), and get the same text in the same language re-aimed at that audience, facts kept and checked, with Replace (#66).

**Architecture:** `Translator` gains `language(for:)` and `repitch(...)`: the existing pipeline with the source equal to the target, a fixed audience and `action: .repitch` carried in its `Context` (prompt, model, no glossary). A new `FactCheck` lists numbers, dates, times, links and email addresses missing from the result; `repitch` appends one warning per missing fact. The app gets a `.choosingAudience` phase, a Re-pitch memory of its own, a hotkey and a menu item.

**Tech Stack:** Swift 6, SwiftPM, Swift Testing, SwiftUI/AppKit (app target only), muter (mutation gate on BabelOtterKit).

**Spec:** `docs/superpowers/specs/2026-10-16-repitch-design.md`

## Global Constraints

- Every source file under `Sources/BabelOtterKit` is ASCII-only (`AsciiSourceTests`): write non-ASCII characters as `\u{...}` escapes.
- BabelOtterKit imports no UI framework.
- In BabelOtterKit: no comma-joined conditions in `if`/`guard`/`while` (including `while let x = ..., cond`), and no ternary whose condition ends in an enum member. Use nested `if`/`guard`.
- Every new kit source file is added to the PASS1 list in `.github/workflows/mutation.yml`.
- Streams stay lazy (`LazyStream`): building one sends nothing.
- `translate(...)`'s behaviour and signatures do not change; the existing `TranslatorTests` must pass unmodified.
- Re-pitch instruction text, exactly: `You are an editor. Rewrite the numbered blocks below for the audience described, in the same language. Change the form of address, the register and the tone to suit that audience. Keep every fact: names, dates, times, numbers, places, links and requests. Do not add or remove information. Do not translate.`
- Re-pitch schema, exactly: `{"blocks": ["..."]}`.
- Fact warning, exactly: `"<fact>" from the original is not in the re-pitch.`
- Popup strings: header "Re-pitch" / "Re-pitch \u{00B7} <language>"; button "Re-pitch"; "Which language is this?"; style placeholder "Style note, e.g. shorter, warmer"; Regenerate help "Re-pitch again with this audience and instruction"; "This looks like <code>, which is not one of your languages."
- Default hotkey `control+option+R`, display "Control-Option-R", key code 0x0F (kVK_ANSI_R), modifiers 0x1800.
- Whole-suite command: `swift test 2>&1 | tail -5`. Integration tests only with `BABELOTTER_INTEGRATION=1`.

## Review Focus

1. A text in an enabled language when three or more languages are enabled: Re-pitch must still find it (it must not go through `TargetLanguageResolver`, which calls that ambiguous). Task 3 pins it with a three-language configuration.
2. Return while the style note field has focus during `.choosingAudience` must start the re-pitch, not do nothing, and never paste (Task 6: `regenerate()` in `.choosingAudience` calls `startRepitch()`).
3. A fact the model reformats ("14:30" to "14.30 Uhr") is reported missing. That is intended: same language, the user should see it. A fact inside a DNT term is restored verbatim, so it is not lost.
4. Picking the audience already shown in `.choosingAudience` must start the run (it is a confirmation), even though `AudienceSession.choose` returns false for the shown audience. Task 6 routes every pick in that phase through `startRepitch()`.
5. Translate's popup must be unchanged: the direction header and Swap show for Translate only; the fact check never runs for Translate (Task 3 pins the kit side).

```swift
import Foundation

/// The facts of a text a rewrite must keep (#66): numbers (dates, times,
/// decimals, ranges), web addresses and email addresses. `missing` lists
/// those of the original that the result does not contain as written.
///
/// A check, not a judgement: a reformatted time is reported too, because in
/// the same language there is no reason to reformat it.
public enum FactCheck {

    public static func missing(from original: String, in result: String) -> [String] {
        var missing: [String] = []
        for fact in facts(in: original) {
            if result.contains(fact) { continue }
            if missing.contains(fact) { continue }
            missing.append(fact)
        }
        return missing
    }

    static func facts(in text: String) -> [String] {
        var found: [String] = []
        for word in text.split(whereSeparator: { $0.isWhitespace }) {
            if let link = link(in: Substring(word)) {
                found.append(link)
            } else {
                found += numbers(in: Array(word))
            }
        }
        return found
    }

    private static let opening: Set<Character> = ["(", "<", "[", "\"", "'"]
    private static let closing: Set<Character> = [".", ",", ";", ":", "!", "?", ")", ">", "]", "\"", "'"]
    private static let joiners: Set<Character> = [".", ",", ":", "/", "-"]

    /// A web or email address, without the punctuation around it.
    private static func link(in word: Substring) -> String? {
        var text = word
        while true {
            guard let first = text.first else { break }
            guard opening.contains(first) else { break }
            text = text.dropFirst()
        }
        while true {
            guard let last = text.last else { break }
            guard closing.contains(last) else { break }
            text = text.dropLast()
        }
        let lower = text.lowercased()
        if lower.hasPrefix("http://") { return String(text) }
        if lower.hasPrefix("https://") { return String(text) }
        if lower.hasPrefix("www.") { return String(text) }
        if isEmail(text) { return String(text) }
        return nil
    }

    private static func isEmail(_ text: Substring) -> Bool {
        guard let at = text.firstIndex(of: "@") else { return false }
        guard at > text.startIndex else { return false }
        return text[text.index(after: at)...].contains(".")
    }

    /// Digit runs, joined into one fact by a single separator between digits.
    private static func numbers(in characters: [Character]) -> [String] {
        var found: [String] = []
        var index = 0
        while index < characters.count {
            if !isDigit(characters[index]) {
                index += 1
                continue
            }
            var end = index
            while end < characters.count {
                if isDigit(characters[end]) {
                    end += 1
                    continue
                }
                guard joiners.contains(characters[end]) else { break }
                guard end + 1 < characters.count else { break }
                guard isDigit(characters[end + 1]) else { break }
                end += 1
            }
            found.append(String(characters[index..<end]))
            index = end
        }
        return found
    }

    private static func isDigit(_ character: Character) -> Bool {
        character >= "0" && character <= "9"
    }
}
```

```swift
private final class ScriptedChat: ChatStreaming, @unchecked Sendable {
    private var replies: [[String]]
    private(set) var prompts: [String] = []
    private(set) var models: [String] = []
    init(_ replies: [[String]]) { self.replies = replies }
    func chat(model: String, messages: [ChatMessage]) -> LazyStream<StreamEvent> {
        LazyStream { [self] in
            models.append(model)
            prompts.append(messages.last?.content ?? "")
            let reply = replies.isEmpty ? [] : replies.removeFirst()
            return AsyncThrowingStream { continuation in
                for piece in reply { continuation.yield(.delta(piece)) }
```

2. Replace the body of the second `translate(_:direction:audience:styleNote:)` with a call to a shared stream builder, and add `repitch` and the builder:

```swift
    public func translate(
        _ text: UserText, direction: Direction, audience: AudienceRequest,
        styleNote: String? = nil
    ) -> LazyStream<TranslationEvent> {
        stream(text, direction: direction, audience: audience, styleNote: styleNote, action: .translate)
    }

    /// The same text in the same language, for `audience` (#66). Always a
    /// fixed audience; no glossary, which is for translating between two
    /// languages; facts of the original that the result lost are warnings.
    public func repitch(
        _ text: UserText, language: LanguageCode, audience: AudienceProfile,
        styleNote: String? = nil
    ) -> LazyStream<TranslationEvent> {
        stream(
            text, direction: Direction(source: language, target: language),
            audience: .fixed(audience), styleNote: styleNote, action: .repitch)
    }

    private func stream(
        _ text: UserText, direction: Direction, audience: AudienceRequest,
        styleNote: String?, action: Action
    ) -> LazyStream<TranslationEvent> {
        LazyStream { [self] in
            AsyncThrowingStream { continuation in
                let task = Task {
                    do {
                        try await run(
                            text, direction: direction, audience: audience,
                            styleNote: styleNote, action: action
                        ) {
                            continuation.yield(checked($0, action: action, original: text.value))
                        }
                        continuation.finish()
                    } catch {
                        continuation.finish(throwing: error)
                    }
                }
                continuation.onTermination = { _ in task.cancel() }
            }
        }
    }

    /// Re-pitch's finished result gains a warning per fact it lost.
    private func checked(
        _ event: TranslationEvent, action: Action, original: String
    ) -> TranslationEvent {
        guard action == .repitch else { return event }
        guard case .finished(let result) = event else { return event }
        let lost = FactCheck.missing(from: original, in: result.text.value).map {
            "\"" + $0 + "\" from the original is not in the re-pitch."
        }
        return .finished(TranslationResult(
            text: result.text, direction: result.direction, warnings: result.warnings + lost,
            audience: result.audience, audienceInferred: result.audienceInferred))
    }
```

```swift
import Foundation
import Testing

@testable import BabelOtterKit

/// The prompt and the configured model must re-aim a text without losing
/// its facts (#66). Local only, like every test that talks to Ollama:
///
///     BABELOTTER_INTEGRATION=1 swift test --filter RepitchIntegrationTests
///
/// The model is not deterministic, so each case runs three times and must
/// pass at least twice. All texts are synthetic.
@Suite(
    "Integration: the model re-pitches a text for another audience",
    .enabled(if: IntegrationGate.isEnabled), .timeLimit(.minutes(10)))
struct RepitchIntegrationTests {

    private let runs = 3

    private func repitch(_ text: String, for audience: AudienceProfile) async throws -> String? {
        let client = OllamaClient(endpoint: .loopback, transport: URLSessionTransport(timeout: 120))
        let translator = Translator(configuration: .default, chat: client)
        guard case .success(let language) = translator.language(for: UserText(text)) else { return nil }
        var finished: String?
        for try await event in translator.repitch(UserText(text), language: language, audience: audience) {
            if case .finished(let result) = event { finished = result.text.value }
        }
        return finished
    }

    private func words(_ text: String) -> [String] {
        text.lowercased().split(whereSeparator: { !$0.isLetter }).map(String.init)
    }

    @Test("a du-form message for Administration uses Sie, no eszett, and keeps its facts")
    func germanToAdministration() async throws {
        let draft = "Hallo Thomas, kannst du mir bis Freitag, 14.11.2026, die Unterlagen schicken? "
            + "Wir treffen uns um 14:30 im Raum B 2.13. Danke dir!"
        var passes = 0
        for _ in 0..<runs {
            let result = try #require(try await repitch(draft, for: .administration))
            let found = words(result)
            var ok = found.contains("sie")
            for informal in ["du", "dich", "dir", "dein", "deine"] where found.contains(informal) { ok = false }
            if result.contains("\u{00DF}") { ok = false }
            if !FactCheck.missing(from: draft, in: result).isEmpty { ok = false }
            if ok { passes += 1 } else { print("re-pitch failed checks: \(result)") }
        }
        #expect(passes >= 2, "passed \(passes) of \(runs)")
    }

    @Test("an English note for Students stays English and keeps its facts")
    func englishToStudents() async throws {
        let draft = "Hi Tom, quick reminder: the review moves to 18 November 2026 at 10:15 "
            + "in room 4.07. Can you bring the slides?"
        let detector = LanguageDetector(configuration: .default)
        var passes = 0
        for _ in 0..<runs {
            let result = try #require(try await repitch(draft, for: .students))
            var ok = detector.detect(result).languageCode?.baseSubtag == LanguageCode("en")
            if !FactCheck.missing(from: draft, in: result).isEmpty { ok = false }
            if ok { passes += 1 } else { print("re-pitch failed checks: \(result)") }
        }
        #expect(passes >= 2, "passed \(passes) of \(runs)")
    }
}
```
