# Explain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select German, press Control-Option-E (or use the menu), and read an English summary of its meaning with notes on its idioms, streamed into the popup, with Copy and no Replace (#65).

**Architecture:** A new `Explainer` in BabelOtterKit, shaped like `Corrector`: German gate, DNT masking, one streaming request with the whole text as one block, the summary streamed through a new `PartialField.prefix`, a strict parse into the existing `ExplainResponse`, terms restored, empty notes dropped. The app's `PopupModel` runs it like Correct (on the selection, no direction), `PopupView` shows the summary and the notes and hides Replace, and Explain gets a hotkey and a menu item.

**Tech Stack:** Swift 6, SwiftPM, Swift Testing, SwiftUI/AppKit (app target only), muter (mutation gate on BabelOtterKit).

**Spec:** `docs/superpowers/specs/2026-10-15-explain-design.md`

## Global Constraints

- Every source file under `Sources/BabelOtterKit` is ASCII-only (`AsciiSourceTests`): write non-ASCII characters as `\u{...}` escapes.
- BabelOtterKit imports no UI framework (`NoUIImportsTests`).
- In BabelOtterKit: no comma-joined conditions in `if`/`guard`/`while`, and no ternary whose condition ends in an enum member (both break muter's schemata). Use nested `if`/`guard` instead.
- Every new kit source file is added to the PASS1 list in `.github/workflows/mutation.yml`.
- The user's text never leaves the machine except to the loopback Ollama endpoint; a stream is lazy (`LazyStream`) so building it sends nothing.
- Copy text format: the summary; when there are notes, a blank line, then one `- "phrase": explanation` line per note.
- Popup strings, exactly: header "Explain"; style note placeholder "Style note, e.g. focus on grammar"; Regenerate help "Explain again with this instruction"; errors "Explain works on German text.", "The model's reply couldn't be read as an explanation. Try Regenerate.", "Nothing came back from the model."
- Default hotkey text `control+option+E`; display name "Control-Option-E"; key code 0x0E (kVK_ANSI_E), modifiers 0x1800.
- Test command for the whole suite: `swift test 2>&1 | tail -5`. Integration tests run only with `BABELOTTER_INTEGRATION=1`.

## Review Focus

1. A model that omits `notes` entirely (rather than `[]`) for a plain sentence: strict decoding makes this `.unreadableReply`. The integration test on a plain sentence (Task 6) is what tells us whether the default model does this; if it does, that is a finding to raise, not to paper over.
2. A summary that does not mention a do-not-translate term must not produce a "may not have been kept" warning (Task 3 pins it): only placeholder debris warns.
3. A stale stream after Regenerate must not overwrite the new run: the app reuses `consume(_:apply:fail:)`, which already guards this; check `runExplanation` goes through it and calls `stop()` first.
4. Explain's popup must never paste: `canReplace` is false for Explain even when finished, and the Replace button is absent, so Return cannot trigger a paste (Task 5).
5. The hotkey plan with a layout lacking "E" (an exotic layout): Explain's default then reports `notOnLayout` as an issue and the other actions keep working; the existing per-action handling covers this, and Task 4's tests add "e" to the test layouts so the defaults resolve.

```swift
public enum PartialField {

    public static func string(named key: String, in partial: String) -> String? {
        guard let read = value(named: key, in: partial) else { return nil }
        guard read.closed else { return nil }
        return read.text
    }

    /// As `string(named:in:)`, but also while the value is still arriving:
    /// as much of it as has come (#65: Explain's summary, streamed).
    public static func prefix(named key: String, in partial: String) -> String? {
        value(named: key, in: partial)?.text
    }

    private static func value(named key: String, in partial: String) -> (text: String, closed: Bool)? {
        guard let found = partial.range(of: "\"" + key + "\"") else { return nil }
        let scalars = Array(partial[found.upperBound...].unicodeScalars)
        var index = PartialBlocks.skipWhitespace(scalars, from: 0)
        guard index < scalars.count else { return nil }
        guard scalars[index] == ":" else { return nil }
        index = PartialBlocks.skipWhitespace(scalars, from: index + 1)
        guard index < scalars.count else { return nil }
        guard scalars[index] == "\"" else { return nil }
        let read = PartialBlocks.readString(scalars, from: index + 1)
        return (read.text, read.closed)
    }
}
```

```swift
    private var replies: [[String]]
```

```swift
import Foundation

public enum ExplanationEvent: Sendable, Equatable {
    case started
    /// Another piece of the reply arrived. Carries nothing; the notes stream
    /// after the summary with no visible change, so this is what tells an
    /// idle timeout the reply is live.
    case progress
    /// The summary so far, post-processed, terms restored. Never the result.
    case summary(String)
    case finished(ExplanationResult)
}

public struct ExplanationResult: Sendable, Equatable {
    public let summary: String
    public let notes: [ExplainNote]
    public let warnings: [String]

    /// What Copy writes: the summary, then one line per note.
    public var copyText: String {
        if notes.isEmpty { return summary }
        let lines = notes.map { "- \"" + $0.phrase + "\": " + $0.explanationEn }
        return summary + "\n\n" + lines.joined(separator: "\n")
    }
}

public enum ExplanationFailure: Error, Equatable {
    /// Detection has a guess, and it is not German. Nothing was sent.
    case notGerman
    /// The reply did not parse, or had no summary. Never shown as an explanation.
    case unreadableReply
    case emptyResponse
}

/// German text in, an English explanation out (`FR-EXP-01`, #65).
///
/// Shaped like `Corrector`, with two differences: the text goes to the model
/// as one block, since a summary has no paragraph layout to keep, and only
/// placeholder debris warns, since an explanation need not repeat a
/// protected term.
public struct Explainer: Sendable {

    /// Explain reads German (spec 2026-10-15). The base subtag, so any
    /// configured German locale qualifies.
    static let german = LanguageCode("de")
    static let english = LanguageCode("en")

    private let configuration: Configuration
    private let chat: any ChatStreaming
    private let detector: LanguageDetector

    public init(
        configuration: Configuration,
        chat: any ChatStreaming,
        recognizer: any LanguageRecognizing = NaturalLanguageRecognizer()
    ) {
        self.configuration = configuration
        self.chat = chat
        self.detector = LanguageDetector(configuration: configuration, recognizer: recognizer)
    }

    /// Lazy for the same reason `OllamaClient.chat` is: building the value
    /// must not transmit the user's text (NFR-P1).
    public func explain(_ text: UserText, styleNote: String? = nil) -> LazyStream<ExplanationEvent> {
        LazyStream { [self] in
            AsyncThrowingStream { continuation in
                let task = Task {
                    do {
                        try await run(text, styleNote: styleNote) { continuation.yield($0) }
                        continuation.finish()
                    } catch {
                        continuation.finish(throwing: error)
                    }
                }
                continuation.onTermination = { _ in task.cancel() }
            }
        }
    }

    // MARK: - The pipeline

    private struct Context {
        let german: LanguageConfig
        let english: LanguageConfig
        let styleNote: String?
        let model: String
        let masked: ProtectedText
        let processor: PostProcessor
    }

    private func run(
        _ text: UserText, styleNote: String?, emit: (ExplanationEvent) -> Void
    ) async throws {
        try gate(text)
        let english = language(Self.english, or: .english)
        let context = Context(
            german: language(Self.german, or: .swissGerman), english: english,
            styleNote: styleNote,
            model: configuration.models[.explain] ?? Configuration.defaultModel,
            masked: TokenProtector.mask(text.value, terms: configuration.doNotTranslate),
            processor: PostProcessor(target: english))
        emit(.started)
        let raw = try await generate(context, emit)
        emit(.finished(try result(raw, context)))
    }

    /// The configured language with this base subtag, so its display name
    /// and locale rules apply; the shipped default otherwise.
    private func language(_ code: LanguageCode, or fallback: LanguageConfig) -> LanguageConfig {
        configuration.enabledLanguages.first { $0.code.baseSubtag == code } ?? fallback
    }

    /// Refuses any guess that is not German. "Can't tell" goes through:
    /// short German fragments are common.
    private func gate(_ text: UserText) throws {
        guard let guess = detector.detect(text.value).languageCode else { return }
        guard guess.baseSubtag == Self.german else { throw ExplanationFailure.notGerman }
    }

    private func generate(
        _ context: Context, _ emit: (ExplanationEvent) -> Void
    ) async throws -> String {
        let prompt = PromptBuilder().build(PromptRequest(
            action: .explain, source: context.german, target: context.english,
            profile: .colleagues, doNotTranslate: configuration.doNotTranslate,
            styleNote: context.styleNote, blocks: [context.masked.text]))
        var shown = ""
        let raw = try await ReplyStream.collect(
            chat: chat, model: context.model, prompt: prompt, key: "notes",
            onRaw: { raw in
                guard let partial = PartialField.prefix(named: "summary_en", in: raw) else { return }
                if partial == shown { return }
                shown = partial
                emit(.summary(context.processor.finish(partial, protected: context.masked).text))
            },
            onDelta: { emit(.progress) },
            onPartial: { _ in })
        if isBlank(raw) { throw ExplanationFailure.emptyResponse }
        return raw
    }

    private func result(_ raw: String, _ context: Context) throws -> ExplanationResult {
        let response: ExplainResponse
        do {
            response = try ResponseParser.parseExplain(raw)
        } catch {
            throw ExplanationFailure.unreadableReply
        }
        let summary = context.processor.finish(response.summaryEn, protected: context.masked)
        if isBlank(summary.text) { throw ExplanationFailure.unreadableReply }
        var problems = summary.problems
        var notes: [ExplainNote] = []
        for item in response.notes {
            // The phrase quotes the user's German: terms restored, no rules.
            let phrase = TokenProtector.restore(item.phrase, from: context.masked)
            let explanation = context.processor.finish(item.explanationEn, protected: context.masked)
            if isBlank(phrase.text) { continue }
            if isBlank(explanation.text) { continue }
            problems += phrase.problems
            problems += explanation.problems
            notes.append(ExplainNote(phrase: phrase.text, explanationEn: explanation.text))
        }
        return ExplanationResult(summary: summary.text, notes: notes, warnings: warnings(problems))
    }

    private func isBlank(_ text: String) -> Bool {
        text.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
    }

    /// A protected term missing from an explanation is normal: it need not
    /// repeat the term. Only a placeholder the model left behind is shown.
    private func warnings(_ problems: [ProtectionProblem]) -> [String] {
        for problem in problems {
            if case .sentinelDebris = problem {
                return ["The model left a placeholder behind; check the text before using it."]
            }
        }
        return []
    }
}
```
